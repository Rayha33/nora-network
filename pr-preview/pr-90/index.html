An open model of the North Sea gas network

NORA maps 70 fields, platforms, plants, terminals and markets, joined by 49 offshore pipelines with a combined length of 12,736 km. It works out how much gas the network can deliver, what happens when any single part fails, and replays recorded flows as if they were arriving live.

It shows the network two ways: on a real map, and as a gas flow overview of the whole Gassco system drawn with pyvis. It is built in Python with networkx, and anyone can improve the data or the code. Every change is checked automatically and published here within minutes of being accepted.

Datasets you can replay

Recorded flows play back on the chart like a live feed: the map follows them hour by hour, pipelines fill and empty, and alarms fire when a flow drops.

Add your own dataset

  1. Get a CSV of flows over time. Any layout works: one row per reading, or one column per point.
  2. Run nora stream new my-data --from flows.csv. It copies the file into data/streams/my-data/ and drafts a stream.toml that maps each point to a pipeline or terminal, guessing by name.
  3. Check the mapping, then run nora stream show my-data to see what was read.
  4. Run nora build to replay it on the chart, or nora live --stream my-data to serve it as a real live feed.

The full guide is in data/streams/README.md.
